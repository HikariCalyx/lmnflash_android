# LMN Flash Android
[Download](https://github.com/HikariCalyx/lmnflash_android/releases/latest)

*This tool is not an officially supported L product, and 100% vibe coded*

A portable smartphone flash tool for L/M/N brand smartphones.

For PC version, please check here: https://github.com/HikariCalyx/lmnflash

## Features
- Lookup Smartphone/Tablet Firmware (L/M/N brands) with IMEI/Device Info/PSN
  - Once you get the link, you can download with any method you like
- Bootloader Unlock (M Smartphones only)
- Firmware Flashing (M Smartphones only, does not support extracted package with flashfile.xml)

## Requirement
- Android 7.0 or newer
- Running on extremely low resolution device is absolutely not encouraged
